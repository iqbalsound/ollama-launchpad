3. Quick fixes

  
Open WebUI shows no models
    
Check curl http://127.0.0.1:11434/api/version and ollama list. In bridge mode, Ollama must be exposed and the URL must be http://host.docker.internal:11434.

  
Page not reachable from another PC
    
Open the firewall port, check hostname -I, and use a bridged network adapter in VirtualBox/VMware.

  
permission denied on docker
    
sudo usermod -aG docker $USER, then log out and back in.
